## 2. Шаги проверки воспроизводимости

Для проверки работоспособности проекта выполнены 5 регламентных шагов:

### Шаг 1. Проверка чистоты версий окружения
```bash
node -v   # Вывод: v22.23.0
npm -v    # Вывод: 10.9.8
git -v    # Вывод: git version 2.50.0.windows.1
```
*Результат:* Версия Node соответствует `.node-version`.

### Шаг 2. Чистая установка зависимостей
```bash
cd frontend
npm ci
```
*Результат:* Зависимости установлены строго по `package-lock.json` без расхождений, уязвимости отсутствуют (`found 0 vulnerabilities`).

### Шаг 3. Демонстрация работы проверки типов компилятора TypeScript
В ходе проверки переменной `appTitle` в файле `src/App.tsx` было присвоено числовое значение:
```typescript
const appTitle: string = 12345
```
Команда `npm run build` завершилась с кодом возврата 1 и зафиксировала ожидаемую ошибку:
```
src/App.tsx(3,7): error TS2322: Type 'number' is not assignable to type 'string'.
```
После восстановления корректного строкового типа `const appTitle: string = 'StudyFlow — Учебный менеджер'` компиляция проходит без ошибок.

### Шаг 4. Проверка production-сборки
```bash
cd frontend
npm run build
```
*Результат:* Успешная трансформация модулей и генерация бандла в `frontend/dist`:
- `dist/index.html` (~0.43 kB)
- `dist/assets/index-*.css` (~1.45 kB)
- `dist/assets/index-*.js` (~221 kB)
Код завершения: 0.

### Шаг 5. Предварительный просмотр сборки
```bash
cd frontend
npm run preview
```
*Результат:* Сервер preview запускается, разметка приложения корректно отображается в браузере, ошибок в консоли разработчика нет.
