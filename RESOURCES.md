# React, TypeScript, and Vite Learning Resources

## Knowledge

- [Vite Official Guide — Getting Started](https://vite.dev/guide/)
  Первоисточник по конфигурированию сборщика Vite, плагинам React, переменным окружения и командам `dev`, `build`, `preview`.
- [React Official Documentation — Describing the UI](https://react.dev/learn/describing-the-ui)
  Официальное руководство по JSX, компонентам как чистым функциям, свойствам (props) и корням React 19.
- [React with TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app/)
  Практический эталон типизации компонентов, хуков, событий и пропсов в современных React-приложениях.
- [TypeScript Handbook — Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)
  Базовые примитивы, объединения, интерфейсы и вывод типов компилятора TypeScript.
- [GitHub Documentation — Ignoring files](https://docs.github.com/en/get-started/git-basics/ignoring-files)
  Правила формирования `.gitignore` и исключения сгенерированных артефактов из истории коммитов.
