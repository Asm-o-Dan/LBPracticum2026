## Лабораторная работа 4: Загрузка справочника приложения по HTTP

**Дата выполнения:** 5 октября 2026 г.  

### 1. Результат лабораторной работы 4

1. **Создан сетевой JSON-справочник:**
   - Файл `frontend/public/demo/tags.json` содержит справочник тегов учебных задач (`lab`, `practice`, `seminar`, `coursework`, `exam`).
   - Ресурс доступен по HTTP по адресу `/demo/tags.json` без префикса `public` и раздаётся dev-сервером Vite, а при сборке включается в `dist/demo/tags.json`.

2. **Описаны типы и runtime-валидация данных:**
   - В `src/types/tag.ts` описан тип `Tag` с полями `id` и `name`.
   - В `src/services/tags.ts` реализован предикат `isTag(value: unknown): value is Tag` для полей объекта и функция `parseTags(value: unknown): Tag[]` для проверки массива и контроля уникальности `id` через `Set`. Типизация не использует небезопасное приведение типов `as Tag[]`.

3. **Выделен изолированный HTTP-сервис:**
   - Функция `getTags(signal: AbortSignal)` в `src/services/tags.ts` отправляет `fetch` с заголовком `cache: 'no-store'`, передаёт `AbortSignal` для отмены и проверяет `response.ok` (выбрасывает ошибку при статусах 404/500).

4. **Разработан хук жизненного цикла `useTags`:**
   - Файл `src/hooks/useTags.ts` инкапсулирует состояние загрузки через дискриминированное объединение `loading | error | success`.
   - `useEffect` использует `AbortController` и локальный флаг `active = true`, чтобы предотвратить изменение состояния после размонтирования компонента.
   - Реализована функция `retry()`, позволяющая повторить сетевой запрос без перезагрузки всей страницы.

5. **Обновлена форма `TaskForm`:**
   - Текстовый ввод тега заменён на выпадающий список `<select>` со значениями из загруженного справочника.
   - Добавлены визуальные состояния: индикатор загрузки (`⏳ Загружаем теги…`), сообщение об ошибке с кнопкой «Повторить», сообщение о пустом справочнике.
   - Сохранение заблокировано (`disabled={!canSave}`) до успешного получения тегов и выбора одного из них.
   - Повторная попытка запроса не сбрасывает введённый пользователем черновик (название, описание, дату).

6. **Согласованы данные и интерфейс:**
   - В `src/data/tasks.ts` демонстрационные теги переведены на строковые идентификаторы (`lab`, `practice`, `coursework`, `seminar`).
   - В карточках списка и на странице деталей код тега отображается с подписью «Тег: ...».
   - Весь функционал ЛР 1–3 (маршрутизация SPA, Layout, CRUD, фильтр по статусу, отмена без мутаций) сохранён в полном объёме.
