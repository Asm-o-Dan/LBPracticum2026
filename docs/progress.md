## Лабораторная работа 5: Схема данных и справочник в Supabase

**Дата выполнения:** 26 октября 2026 г.  

### 1. Результат лабораторной работы 5

1. **Спроектирована и применена реляционная схема в PostgreSQL (Supabase):**
   - Файл миграции: [`supabase/migrations/202610260001_initial_schema.sql`](file:///c:/Users/DaniilTuT/Documents/antigravity/excited-franklin/supabase/migrations/202610260001_initial_schema.sql).
   - Таблица `public.tags` (справочник): первичный ключ `id text`, уникальное имя `name text`, проверки `btrim(id) <> ''` и `btrim(name) <> ''`.
   - Таблица `public.tasks` (основная сущность): первичный ключ `id uuid default gen_random_uuid()`, внешний ключ `tag_id references public.tags(id) on update cascade on delete restrict`, внешний ключ `owner_id references auth.users(id) on delete cascade`, проверки допустимых статусов (`todo`, `in_progress`, `done`), приоритетов (`low`, `medium`, `high`) и длины названия (от 3 до 100 символов).

2. **Настроена многоуровневая безопасность (RLS и GRANT):**
   - На обеих таблицах включен Row Level Security (`alter table ... enable row level security`).
   - Отозваны все права по умолчанию у клиентских ролей `anon` и `authenticated`.
   - Для таблицы `tags` выдан `GRANT SELECT` и настроена политика `"tags are publicly readable"` (`for select to anon, authenticated using (true)`). Клиентская запись в справочник запрещена.
   - Для таблицы `tasks` права и политики не создавались — таблица полностью закрыта для прямого доступа от клиентских ролей до ЛР 6.

3. **Воспроизводимое начальное наполнение (Seed):**
   - Файл [`supabase/seed.sql`](file:///c:/Users/DaniilTuT/Documents/antigravity/excited-franklin/supabase/seed.sql) содержит `UPSERT` для 5 учебных тегов (`lab`, `practice`, `seminar`, `coursework`, `exam`). Повторный запуск seed безопасен и не плодит дубликаты.

4. **Интеграция официального клиента Supabase в React:**
   - Установлен пакет `@supabase/supabase-js`.
   - Настроены файлы переменных окружения: `frontend/.env.local` (с секретными ключами, добавлен в `.gitignore`) и `frontend/.env.example` (с шаблонами для воспроизведения).
   - Инициализирован общий синглтон клиента [`frontend/src/lib/supabase.ts`](file:///c:/Users/DaniilTuT/Documents/antigravity/excited-franklin/frontend/src/lib/supabase.ts) с валидацией наличия URL и Publishable Key.

5. **Переключение источника данных и обновление формы:**
   - Удален статический файл `public/demo/tags.json`.
   - В сервисе [`src/services/tags.ts`](file:///c:/Users/DaniilTuT/Documents/antigravity/excited-franklin/frontend/src/services/tags.ts) функция `getTags` переписана на запрос `supabase.from('tags').select('id, name').order('name').abortSignal(signal)`.
   - В `TaskForm.tsx` добавлена кнопка «🔄 Обновить справочник», вызывающая `retry()` без отправки формы. Черновик задачи при обновлении справочника сохраняется.
   - Сохранена строгая runtime-валидация через `parseTags` и предикат `isTag`.
