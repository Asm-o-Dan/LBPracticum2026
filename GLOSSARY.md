# React & Modern Web Development Glossary

Канонические термины и определения курса веб-разработки (React, TypeScript, Vite, Node).

## Terms

**JSX (JavaScript XML)**:
Синтаксическое расширение JavaScript, позволяющее описывать структуру пользовательского интерфейса в виде древовидной разметки, транспилируемой компилятором в вызовы функций `_jsx()`.
_Avoid_: HTML в скриптах, шаблонный язык

**SPA (Single Page Application)**:
Веб-приложение, загружающее единственную HTML-страницу (`index.html`) и динамически обновляющее DOM на стороне клиента через JavaScript без перезагрузки страницы сервером.
_Avoid_: Одностраничник, статичный сайт

**Vite**:
Инструмент сборки фронтенда, использующий нативные ES-модули браузера для мгновенного горячего обновления модулей (HMR) в dev-режиме и Rollup для оптимизированной production-сборки.
_Avoid_: Вебпак-заменитель, компилятор файлов

**HMR (Hot Module Replacement)**:
Механизм среды разработки, при котором измененный модуль приложения обновляется в работающем браузере на лету через WebSocket без полной перезагрузки страницы и без потери текущего состояния.
_Avoid_: Автообновление страницы, live reload

**`package-lock.json`**:
Детерминированный манифест зависимостей, фиксирующий точные версии, контрольные суммы хэшей и дерево пакетов для повторяемой установки через команду `npm ci`.
_Avoid_: Копия package.json, кэш npm

**`tsc -b` (TypeScript Project References Build)**:
Режим компилятора TypeScript, собирающий проекты по графу зависимостей `tsconfig.json` с проверкой типов без вывода JavaScript (при `noEmit: true`).
_Avoid_: Рантайм-чекер, валидатор

**Fetch API**:
Встроенный стандарт браузера для отправки асинхронных HTTP-запросов, возвращающий `Promise`. Не отклоняет промис при HTTP-кодах ошибок (404, 500).
_Avoid_: Библиотека Axios, jQuery AJAX

**`response.ok`**:
Булево свойство ответа `Response`, равное `true`, если HTTP-статус находится в диапазоне успешных кодов 200–299.
_Avoid_: Проверка промиса, проверка статус-текста

**`AbortController`**:
Стандартный интерфейс веб-платформы, позволяющий принудительно прерывать асинхронные DOM-операции и HTTP-запросы через ассоциированный объект `AbortSignal`.
_Avoid_: Таймаут отмены, отписка RxJS

**Runtime Type Guard (Пользовательский предикат типа)**:
Функция с сигнатурой `value is T`, проверяющая фактическую структуру и типы неизвестных данных во время выполнения в JavaScript и сужающая тип переменной в TypeScript.
_Avoid_: Type Assertion (`as`), кастинг типов

**Дискриминированное объединение (Discriminated Union)**:
Шаблон моделирования состояний в TypeScript с общим строковым полем-дискриминатором (например, `status: 'loading' | 'error' | 'success'`), делающий невозможными неконсистентные состояния.
_Avoid_: Множественные boolean-флаги (isLoading, isError, isSuccess)
