# Mission: Web Development with React, TypeScript, Node.js, and Supabase

## Why
Сдать практический курс веб-разработки в ГОУ «ПГУ им. Т.Г. Шевченко» на высший балл (10/10), освоить промышленный стек React + TypeScript + Node.js + Supabase и разработать рабочий семестровый веб-сервис StudyFlow для управления учебными заданиями, дедлайнами и проектами.

## Success looks like
- Защита всех 10 лабораторных работ преподавателю Бричагу Д.В. с первого раза без замечаний.
- Уверенное владение компонентной моделью React 19, строгой типизацией TypeScript и инструментами сборки Vite.
- Понимание жизненного цикла сборки, связей `index.html` → `main.tsx` → `App.tsx`, различий между dev-сервером, production-сборкой и preview.
- Запущенный и доступный репозиторий с воспроизводимым развертыванием через `npm ci`.

## Constraints
- Стек строго по учебной программе кафедры ИТ: React, TypeScript, Vite, Node.js, Supabase, Git.
- Соблюдение стандартов кодирования, чистоты репозитория и исключение бинарных/служебных файлов из Git.
- Никакой ИИ-воды и заученных абстракций: ответы на защите должны быть четкими, конкретными и технически выверенными.

## Out of scope
- Использование альтернативных фреймворков (Vue, Angular, Svelte, Next.js).
- Разработка бэкенда и БД на этапе ЛР 1 (отложено до ЛР 8–10 по плану курса).
