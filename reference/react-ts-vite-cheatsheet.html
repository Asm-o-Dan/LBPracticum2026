Справочник: React + TypeScript + Vite

Ключевая анатомия проекта, команды сборщика и типовые паттерны типизации.

1. Команды проекта

CLI Ежедневный цикл разработки:

# Запуск dev-сервера (HMR на 5173)
npm run dev

# Проверка типов + сборка в dist
npm run build

# Локальный preview готового dist
npm run preview

# Строгая установка из lock-файла
npm ci

2. Цепочка монтирования

DOM → React От HTML до компонента:

index.html:
<div id="root"></div>
<script type="module" src="/src/main.tsx"></script>

main.tsx:
createRoot(document.getElementById('root')!)
  .render(<StrictMode><App /></StrictMode>)

App.tsx:
export default function App() { ... }

3. Различия режимов запуска

Режим Команда Механизм Назначение
Dev npm run dev Нативные ES-модули, Fast Refresh HMR без бандлинга Разработка с мгновенным откликом
Build npm run build tsc -b (проверка типов) + Rollup (минификация, бандлинг в dist/) Подготовка к релизу и проверке
Preview npm run preview Статический веб-сервер над папкой dist/ Проверка итоговой сборки перед деплоем

4. Правила чистоты Git

В репозиторий включаются только декларации и исходники: package.json, package-lock.json, .node-version, исходный код и документация. Директории node_modules/ и dist/ всегда исключаются через .gitignore, так как являются генерируемыми артефактами.
