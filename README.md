## 1. Описание и основной сценарий

**StudyFlow** помогает студенту отслеживать семестровые курсы, дедлайны по лабораторным работам и статус выполнения практических заданий. Пользователь просматривает список дисциплин, видит ближайшие сроки сдачи, отмечает сданные работы и контролирует учебную нагрузку по семестру.

## 3. Инструкция по установке и запуску

### Требования к окружению
- Установленный Node.js версии `22.x` (проверить: `node -v`)
- Git (проверить: `git -v`)

### Запуск в режиме разработки
Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

После запуска откройте в браузере локальный адрес (по умолчанию `http://localhost:5173`).

### Проверка сборки и preview

```bash
cd frontend
npm run build
npm run preview
```

Команда `npm run build` выполняет строгую проверку типов TypeScript (`tsc -b`), после чего Vite формирует оптимизированные статические файлы в директории `frontend/dist`. `npm run preview` поднимает локальный HTTP-сервер для проверки собранного бандла.
